# Ampliación 01. Tres conceptos distintos

[Volver a ampliaciones](README.md)

**Pregunta guía:** ¿en qué se diferencian una **JVM**, una **máquina virtual VirtualBox/KVM** y un **contenedor Docker**?

- **JVM:** plataforma de ejecución del bytecode Java, con servicios de memoria y ejecución.
- **Máquina virtual de sistema:** emula o virtualiza un entorno de hardware para ejecutar un sistema operativo invitado.
- **Contenedor:** aísla procesos compartiendo el núcleo del sistema anfitrión (en Linux), con capas de software y herramientas propias.

**Propuesta:** dibujar las tres arquitecturas en un esquema, identificar su nivel de aislamiento y proporcionar un ejemplo de uso DAW.

**Precaución:** Docker Desktop puede usar una VM en sistemas Windows/macOS; el modelo general de contenedores no equivale a una VM completa.
