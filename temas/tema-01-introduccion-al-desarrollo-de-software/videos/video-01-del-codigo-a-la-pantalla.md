# Vídeo 01. Del código fuente a la pantalla

## Objetivo

Mostrar visualmente cómo un pequeño programa escrito en un editor se convierte en acciones realizadas por el ordenador.

## Guion por escenas

| Tiempo orientativo | Imagen / animación | Narración |
|---|---|---|
| 00–12 s | Editor con un archivo hola.py y botón Guardar | «Este es el código fuente: texto que escribimos y guardamos.» |
| 12–25 s | Archivo almacenado; terminal ejecuta python3 hola.py | «Para ejecutarlo necesitamos un entorno que interprete sus instrucciones.» |
| 25–43 s | RAM, proceso, CPU y sistema operativo, con flechas | «El programa en ejecución utiliza memoria, procesador y servicios del sistema.» |
| 43–60 s | Terminal muestra Hola, mundo | «Esta es la salida. El editor, el intérprete y la CPU cumplen funciones distintas.» |
| 60–80 s | Comparación breve fuente C → objeto → ejecutable | «Otra ruta posible utiliza compilación y enlace antes de ejecutarse.» |

## Prompt de producción futura

Animación vectorial educativa limpia, formato horizontal 16:9, alto contraste, etiquetas españolas legibles, flechas con transiciones breves; representar código, terminal, RAM, CPU y pantalla; evitar metáforas donde el texto Python llegue directamente a la CPU sin intermediación; sin logos inventados ni datos personales.

## Revisión de exactitud

- No atribuir a la CPU ejecución directa del texto fuente.
- Diferenciar interpretación de compilación y ejecución de máquina.
- No presentar toda la RAM como almacenamiento permanente.
- Añadir subtítulos y comprobar legibilidad.
