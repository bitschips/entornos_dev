# Actividad 04. Comparativa de herramientas y entornos de desarrollo

[Volver al índice de actividades](README.md) · [Volver al tema](../tema-01.md)

**RA:** RA1.f y aproximación a RA2.g · **Duración:** 50–60 minutos · **Formato:** individual.

## Objetivo

Diferenciar lenguaje, editor, IDE, runtime y extensiones; justificar la elección de una herramienta para un proyecto DAW.

## Pasos

1. Elige **tres herramientas**: por ejemplo **VS Code**, **IntelliJ IDEA**, **Eclipse**, **NetBeans**, **PyCharm** o **Geany**. Indica si comparas una edición gratuita o de pago; no presupongas que todas las ediciones tienen las mismas funciones.
2. Consulta sus páginas oficiales y verifica fecha de consulta.
3. Prepara la tabla, usando información comprobable:

| Campo | Herramienta A | Herramienta B | Herramienta C |
|---|---|---|---|
| Desarrollador / mantenedor | | | |
| URL oficial | | | |
| Editor o IDE; explica por qué | | | |
| Sistemas operativos disponibles | | | |
| Lenguajes soportados | | | |
| Extensiones, terminal y depuración | | | |
| Instalación local / opción web comprobada | | | |
| Captura de pantalla identificada | | | |

4. Propón una herramienta para cada proyecto: **script Python**, **proyecto Java**, **sitio web HTML/CSS/JS**.
5. Explica en cinco líneas por qué una herramienta no es por sí sola un compilador o un lenguaje.
6. Añade las **fuentes** y fecha de cada afirmación que pueda cambiar.

## Evidencias y evaluación

- Tabla completa con enlaces y capturas referenciadas.
- Justificación por proyecto y conclusión propia.

- [ ] Fuentes oficiales y enlaces funcionales.
- [ ] Distinción correcta entre lenguaje, editor, IDE y runtime.
- [ ] Sistemas/plataformas y licencias verificadas.
- [ ] Comparativa razonada, no basada solo en preferencias.

**Ampliación:** investigar una extensión concreta y el problema que resuelve. No instalar extensiones desconocidas en equipos del centro sin permiso.
