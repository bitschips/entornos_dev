Entornos de Desarrollo · Tema 04

1. ¿Qué es desarrollar software?

Un programa informático es un conjunto organizado de instrucciones y datos que un sistema puede ejecutar para realizar una tarea.
Una aplicación suele integrar uno o varios programas, recursos y configuración para resolver necesidades de una persona o empresa.
Desarrollar software no es solo escribir instrucciones. Significa comprender un problema, diseñar una solución, implementarla, comprobar su funcionamiento, distribuirla y mantenerla .
Ejemplo DAW: una web de reservas de pistas deportivas necesita interfaz, lógica que compruebe horarios, almacenamiento de reservas y pruebas para evitar duplicidades.

El almacenamiento conserva programas y archivos entre arranques. Los periféricos permiten introducir y presentar información.

2. ¿Cómo se ejecuta un programa en un ordenador?

El programa está almacenado como archivo, o se recibe desde un servicio.
El sistema prepara un proceso y dispone el código y los datos necesarios en memoria.

Se producen resultados: texto, archivos, imagen o respuesta de red.

4. Código fuente, objeto, ejecutable e intermedio

Código fuente: texto escrito en un lenguaje de programación y destinado a ser procesado por un entorno o herramienta.
Código objeto: salida intermedia habitual de un compilador, especialmente en lenguajes como C; contiene código y referencias que pueden necesitar un enlazador .
Ejecutable nativo: archivo o conjunto preparado para arrancar un programa en una plataforma determinada.
El código intermedio es una representación diseñada para otra fase de ejecución, por ejemplo el bytecode de Java , que utiliza una máquina virtual.

5. Lenguajes de programación y paradigmas

Un lenguaje de programación ofrece reglas de sintaxis y semántica para expresar algoritmos. Los lenguajes se diferencian por sus características, no por una única clasificación en «mejores» o «peores».
Imperativo / procedimental: pasos y cambios de estado (C o partes de Python).
Orientado a objetos: objetos, atributos y métodos (Java, C#, Python).
Funcional: funciones y transformación de datos (Haskell, funciones de JavaScript y Python).

Entornos de Desarrollo · Tema 30

8. Caso integrador: de una necesidad al «Hola, mundo»

Necesidad: demostrar que tenemos el entorno listo para construir programas. Análisis: debe mostrar un mensaje. Diseño: entrada ninguna; salida una línea de texto.
Implementación: un archivo con una instrucción. Pruebas: ejecutar y comparar la salida con el mensaje esperado. Entrega: guardar archivo fuente y explicación de ejecución.
Si falla la ejecución , comprobar ruta actual, nombre del archivo, sintaxis, instalación del intérprete/compilador y mensajes de error antes de cambiar el programa al azar.
El concepto importante no es memorizar una instrucción: es comprender quién traduce o ejecuta el código, dónde está el programa y cómo se comprueba el resultado .
