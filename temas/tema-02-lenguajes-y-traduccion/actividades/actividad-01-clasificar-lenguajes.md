# Actividad 01. Clasificar lenguajes sin confundir criterios

[Índice de actividades](README.md) · [Tema 2 en revisión](../REVISION-tema-02.md)

**RA1.e · Duración orientativa:** 45–55 min · **Agrupamiento:** parejas.

## Reto

Una empresa DAW debe elegir tecnologías para distintas partes de una aplicación. Distingue **nivel de abstracción**, **paradigma** y **cadena de ejecución**.

## Procedimiento

1. Completa una tabla para **C, Java, Python, JavaScript, ensamblador x86 y SQL**.
2. En «nivel», clasifica como máquina / ensamblador / alto nivel cuando proceda.
3. Indica al menos un paradigma aplicable (no fuerces una única categoría).
4. En «cadena habitual», describe qué herramientas o runtime intervienen en una implementación concreta.
5. Justifica por qué SQL no se usa para programar el mismo tipo de lógica que un lenguaje de propósito general.
6. Busca **dos lenguajes multiparadigma** y ofrece un ejemplo breve de cada uno.
7. Identifica **dos afirmaciones incorrectas** entre:
   - «Alto nivel significa interpretado».
   - «Java necesita una JVM compatible para ejecutar normalmente su bytecode».
   - «Los lenguajes tienen siempre una sola implementación».
   - «Un compilador solo puede producir código máquina».
8. Redacta un resumen de 5 líneas: ¿qué **tres preguntas** harías antes de clasificar un lenguaje?

Entregar el documento y URLs de fuentes técnicas fiables.

- [ ] Distingue los tres criterios de clasificación.
