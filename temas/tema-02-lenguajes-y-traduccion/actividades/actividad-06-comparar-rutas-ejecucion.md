# Actividad 06. Tres caminos, el mismo resultado

[Índice de actividades](README.md) · [Tema 2 en revisión](../REVISION-tema-02.md)

**RA1.c–f · Duración:** 45–60 min · **Formato:** grupos de 3.

## Reto

Comparad C, Python y Java a partir de una tarea equivalente: **mostrar la suma de dos números enteros**. El objetivo es comprender las herramientas y archivos que intervienen, **no medir rendimiento**.

## Pasos

1. Un miembro ejecuta un ejemplo en C con GCC; otro en Python 3; el tercero en Java con JDK, si están disponibles. Si falta un entorno, analizad su cadena a partir de los ejemplos teóricos sin inventar una ejecución.
2. Registrad extensión de fuente, comando de transformación y comando de ejecución.
3. Identificad archivos intermedios observables, con su extensión.
4. Dibujad las tres cadenas de forma paralela con flechas y etiquetas correctas.
5. Contestad: ¿cuáles necesitan runtime? ¿Qué diferencias hay entre bytecode y objeto? ¿Qué necesitaría un segundo equipo para ejecutar cada caso?
6. Presentad una explicación oral de 2 minutos usando el diagrama del grupo.
